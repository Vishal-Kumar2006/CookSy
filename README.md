<h1>🍽️ CookSy</h1>

<p><strong>A MERN Stack Recipe-Sharing Platform for Food Lovers</strong></p>

<p>
🚀 <strong>CookSy</strong> is a full-stack web application where food lovers can 
explore, share, and discover recipes based on meal types and cooking methods. 
It is built using the <strong>MERN stack (MongoDB, Express.js, React.js, Node.js)</strong> 
and is designed to make cooking discovery simple, creative, and enjoyable. ❤️
</p>

<h2>🚀 Getting Started (Local Setup)</h2>

<h3>1. Clone the Repository</h3>
<pre>
git clone https://github.com/yourusername/CookSy.git
cd CookSy
</pre>

<h3>2. Install Dependencies</h3>

<p><strong>Backend:</strong></p>
<pre>
cd backend
npm install
</pre>

<p><strong>Frontend:</strong></p>
<pre>
cd ../frontend
npm install
</pre>

<h3>3. Run the Project</h3>

<pre>
# Backend
npm run start

# Frontend
npm run dev
</pre>

<p>Open in browser: <code>http://localhost:3000</code></p>
